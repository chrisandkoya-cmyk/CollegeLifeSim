ดาวน์โหลดและติดตั้งเกม CollegeLifeSim

ดาวน์โหลดฟรีทั้งสำหรับคอมพิวเตอร์ระบบ Windows (.exe) และสมาร์ตโฟนระบบ Android (.apk) พร้อมสแกนคิวอาร์โค้ดได้ทันที

⬇ ดาวน์โหลดไฟล์ .apk (Google Drive)
คู่มือการติดตั้งบนคอมพิวเตอร์

💻 วิธีติดตั้งบนระบบปฏิบัติการ Windows

  1. คลิกปุ่ม ดาวน์โหลดไฟล์ .exe ด้านบน หรือสแกนคิวอาร์โค้ดเพื่อดาวน์โหลดไฟล์ CollegeLifeSim_Setup_1.0.4.exe จาก Google Drive
  2. ดับเบิลคลิกเปิดไฟล์ที่ดาวน์โหลดมา หากหน้าต่าง Windows SmartScreen แจ้งเตือน ให้คลิก More info (ข้อมูลเพิ่มเติม) แล้วกดปุ่ม Run anyway (เรียกใช้ต่อไป)
  3. ทำตามขั้นตอนของตัวติดตั้ง (สามารถเลือกสร้างไอคอนทางลัดบนหน้าจอ Desktop ได้)
  4. เมื่อติดตั้งเสร็จสมบูรณ์ ให้ดับเบิลคลิกไอคอน CollegeLifeSim บนหน้าจอเพื่อเริ่มเล่นได้ทันทีโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต
คู่มือการติดตั้งบนโทรศัพท์มือถือ

📱 วิธีติดตั้งบนระบบปฏิบัติการ Android

  1. ใช้กล้องโทรศัพท์มือถือสแกนคิวอาร์โค้ดฝั่ง Android หรือกดปุ่ม ดาวน์โหลดไฟล์ .apk เพื่อบันทึกไฟล์ CollegeLifeSim.apk ลงในเครื่อง
  2. แตะเปิดไฟล์ CollegeLifeSim.apk จากแถบแจ้งเตือนหรือแอปจัดการไฟล์ (File Manager)
  3. หากระบบสอบถามสิทธิ์ความปลอดภัย ให้เลือก การตั้งค่า (Settings) → อนุญาตให้ติดตั้งแอปจากแหล่งที่ไม่รู้จัก (Allow from this source)
  4. กดปุ่ม ติดตั้ง (Install) รอสักครู่แล้วกด เปิด (Open) ตัวเกมจะปรับเข้าสู่มุมมองแนวนอนพร้อมปุ่มสัมผัสบนหน้าจอโดยอัตโนมัติ

ฮาร์ดแวร์และซอฟต์แวร์ที่ใช้พัฒนาโครงงาน

  • เครื่องคอมพิวเตอร์ที่ใช้พัฒนา: ซีพียู AMD Ryzen 7 260 (3.80 GHz) · การ์ดจอ NVIDIA GeForce RTX 5060 Laptop GPU ร่วมกับ AMD Radeon 780M · RAM 16 GB · พื้นที่เก็บข้อมูล 477 GB · ระบบปฏิบัติการ Windows 11 (64-bit)
  • สมาร์ตโฟนที่ใช้ทดสอบระบบแอนดรอยด์: โทรศัพท์มือถือระบบปฏิบัติการแอนดรอยด์ของคณะผู้จัดทำ จำนวน 3 เครื่อง
  • โปรแกรมพัฒนาเกมหลัก: โปรแกรม Godot Engine 4 (รุ่น 4.6) และชุดคำสั่งภาษา GDScript (จำนวน 52 สคริปต์ 26,337 บรรทัด)
  • โปรแกรมออกแบบกราฟิกและเอกสาร: Adobe Photoshop, Canva, Microsoft Word และ Google Forms (สำหรับเก็บรวบรวมข้อมูลความพึงพอใจ)

ประวัติการพัฒนาตั้งแต่รุ่นต้นแบบถึงรุ่นสมบูรณ์ (Demo 0.2 – Demo 1.0.4)

เวอร์ชัน สถานะ รายละเอียดการพัฒนาและปรับปรุงระบบ
Demo 1.0.4 (ปัจจุบัน) รุ่นสมบูรณ์พร้อมส่งมอบ ปรับปรุงประสิทธิภาพการแสดงผลทั้งบน Windows (.exe) และ Android (.apk) เพิ่มโหมดสนามประลองแมพพิเศษ (บลู ราชาทองคำ) คัตซีนท่าไม้ตาย วิดีโอเทรลเลอร์ทางการ และแผ่นติดตั้ง CD-ROM Autorun (CollegeLifeSim_CD_1.0.4.iso)
Demo 1.0.2 – 1.0.3 อัปเดตเนื้อหาเสริม เพิ่มระบบสร้างตัวละครจากภาพถ่าย (Photo-to-NPC) ทรงผม 35 แบบ เครื่องประดับ 67 ชิ้น ระบบการ์ดสะสม 30 ใบ และฉากจบครบ 11 รูปแบบ
Demo 0.75 – 0.9 ทดสอบกลุ่มตัวอย่าง ครบทั้ง 9 คาบเรียน มินิเกมประจำวิชา 7 รูปแบบ กิจกรรมองค์การวิชาชีพวันศุกร์ ระบบบันทึกเกม 3 ช่อง และนำไปทดลองใช้กับกลุ่มตัวอย่างนักศึกษา ปวส. จำนวน 27 คน
Demo 0.2 – 0.5 รุ่นต้นแบบ (Prototype) วางโครงสร้างแผนที่วิทยาลัยเทคโนโลยีหลวงปู่สรวงวัดไพรพัฒนา อาคารเรียน 3 ชั้น โรงอาหาร ระบบเวลา 06:00–16:30 น. และระบบความหิว
